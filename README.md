# agent-controlled-wallet

This project enables AI models to autonomously manage blockchain funds and perform actions that would traditionally require human input. Through a unified, chain-agnostic wallet SDK—supporting Ethereum, Solana, and future chains—an AI can:
- Sign transactions and messages
- Interact with smart contracts
- Perform swaps and other DeFi operations
- Deploy its own smart contracts or logic modules on supported networks
- Maintain full cryptographic auditability of decisions

## Example Vision

An AI agent could independently deploy code to blockchain nodes, manage resources, and evolve its capabilities by creating or modifying smart contracts—acting as a self-directed, verifiable autonomous system.

## wallet-core

A modular, multi-chain wallet framework built for AI-driven interaction with blockchain networks. This project implements a unified wallet interface and chain-specific wallet implementations (Ethereum, Solana), along with utilities for smart contract interaction.
